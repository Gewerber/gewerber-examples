# 🧪 Gewerber Examples

Deployment examples, Docker Compose setups, demo projects, and quickstart configurations for **Gewerber**.

Part of the [Gewerber GitHub organization](https://github.com/Gewerber).

---

## 📦 Contents

This repository contains runnable examples that show how to deploy and use Gewerber components:

- Docker Compose setups (Serverpod + PostgreSQL)
- Quickstart / demo projects
- Sample integrations

Each example lives in its own directory with its own `README.md`.
